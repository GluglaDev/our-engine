01 / About the project

Small steps.
Independent foundations.

OUR Engine is being developed from an experimental prototype. The current focus is the rendering pipeline: understanding HTML, applying basic CSS rules, calculating layout and drawing pixels to a window.

CURRENT STATUS Early experimental prototype

HTML parsing, a simplified DOM, basic CSS handling, preliminary box-model calculations and text rendering are under development. Modern website compatibility is not yet available.

02 / Technology

A rendering engine,
not a browser wrapper.

R

Rust

The primary implementation language for the experimental engine.

⌘

HTML parsing

HTML input is parsed with html5ever and represented in a simplified DOM.

▦

CSS & layout

A custom, experimental CSS and layout implementation is being expanded incrementally.

◫

Text & graphics

Text rasterization and framebuffer drawing form the current output path.

The prototype uses supporting libraries such as html5ever, markup5ever_rcdom, fontdue, minifb and ureq. These are not embedded browser engines.
